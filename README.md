# learn-data-pmo-with-phoebe

A free, hands-on, two-track course on running a data office's project portfolio - by Phoebe Fu.

**Live site:** https://phoebefu6.github.io/learn-data-pmo-with-phoebe/

## What it covers

One running case: Northgate, a 120-store retailer, stands up a data office - 30 catalog services (Infrastructure, Data Analytics, Data Science, Gen AI) rolled into 10 projects, 14 people, $2,700k, 12 months.

- **Leader track (6 x 45 min):** the Data PMO operating model, annual roadmap, budget + cost, headcount + R&R, stakeholders + steering, portfolio health.
- **Practitioner track (10 x 45 min):** portfolio intake, roadmap to timeline, sprint planning for data work, RACI, timeline management, stakeholder management, time management, conflict management, budget + cost management, headcount + capacity capstone.
- **The portfolio simulator (b5 + a6):** 10 projects live in your browser - toggle RACI, sprint cadence, steering, capacity plan, and budget buffer and watch on-time delivery climb 1 → 9 of 10 and the overrun collapse +38% → +1%. Then press the Brooks's-law anti-lever and learn why crashing a late project backfires.

Taught from stable primary sources: Scrum Guide 2020, PMBOK Guide 7th ed, The Mythical Man-Month, Thomas-Kilmann conflict modes, CRISP-DM, standard EVM formulas.
